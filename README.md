# RokaDex Engineering Studio — Alpha 1.3

تطبيق مستقل لتصميم الخزائن والغرف ومعاينة قوائم القص والألواح. بُني على نسخة Alpha 1.1 المرفوعة، مع الحفاظ على المحركات الحالية وملفات المشاريع v1/v2. لا يتصل بتطبيق RokaDex SaaS.

**نسخة هندسية تجريبية: المخرجات غير معتمدة للتصنيع أو CNC.**

## التشغيل

يلزم Node.js 24 LTS وnpm. من جذر المستودع:

```sh
npm ci
npm run dev
```

شغّل `npm run build` لإنتاج مجلد `dist`، ثم `npm run preview` لمراجعته محليًا. لا تستخدم فتح `index.html` مباشرة أو خادم Python على ملفات المصدر: يستلزم المصدر حل اعتماديات npm عبر Vite. يمكن تقديم ملفات `dist` بواسطة أي خادم ملفات ثابتة. لا تحتاج الحزمة المبنية إلى CDN أو مفاتيح API أو حساب.

## الاختبارات

```sh
npm test
npm run build
npm run test:e2e
```

تستخدم اختبارات المتصفح Chromium النظام عند وجوده في `/usr/bin/chromium`، أو المسار المحدد في `CHROMIUM_PATH`. على جهاز آخر، ثبّت متصفح Playwright أولًا:

```sh
npx playwright install --with-deps chromium
npm run verify
```

تعمل اختبارات المتصفح على **حزمة الإنتاج** وتغطي التشغيل مع حظر الطلبات الخارجية، تعديل الأبعاد والرفوف والأدراج، التراجع والإعادة، الاستعادة بعد تحديث الصفحة، استيراد v1/v2، رفض ملف ضار، تصدير CSV وSVG وPNG، والتنقل والعرض والترجمة العربية. لا تُعد الاختبارات البرمجية اعتمادًا هندسيًا للتصنيع.

## Cloudflare Pages

- Framework preset: **None**.
- Root directory: جذر المستودع، وليس `rokadex-standalone`.
- Build command: `npm run build`.
- Build output directory: `dist`.
- Node.js: `24`.

في النشر اليدوي، ارفع **محتويات `dist`** ليكون `index.html` في جذر الموقع. يتضمن `wrangler.toml` تعريف مجلد الإخراج، و`public/_headers` ترويسات تُنسخ إلى الحزمة. التطبيق صفحة واحدة دون مسارات مخصصة؛ تحديث الصفحة الرئيسية لا يحتاج تهيئة توجيه إضافية.

لم يُنفّذ نشر إلى حساب Cloudflare أو تحقق من رابط إنتاج مستضاف. لا تتضمن هذه النسخة بيانات اعتماد للنشر.

## استخدام المشروع

- أضف الوحدات من المكتبة واضبط الأبعاد والتقسيمات والرفوف والأدراج من الخصائص.
- حدّد لوحًا من قائمة القص لتعديل تلبيس حوافه أو معاينة تفاصيله.
- احفظ نسخة JSON لنقل المشروع أو حفظ نسخة مستقلة. يمكن فتح ملفات الإصدارين 1 و2.
- الحفظ التلقائي محلي لهذا المتصفح وهذا الموقع فقط؛ ليس نسخة سحابية. قد يمسحه المتصفح أو الوضع الخاص. يظهر فشل التخزين بدل الادعاء بالحفظ.
- يحتفظ التراجع والإعادة بآخر 30 حالة خلال الجلسة. `Ctrl/Cmd+Z` و`Ctrl/Cmd+Shift+Z` يعملان خارج حقول التحرير. التراجع داخل الحقول يتبع المتصفح.
- زر اللغة يبدل العربية والإنجليزية ويحفظ اختيار اللغة. التقارير الهندسية وبعض رسائل الأخطاء الديناميكية ما زالت بالإنجليزية.
- افتح `samples/kitchen-concept.json` من زر Open لتجربة ثلاث وحدات مطبخ.

## الجديد في Alpha 1.3

- مخطط غرفة تفاعلي بالتحديد والدوران الربعي، ومحاذاة الوحدات والجدران وشبكة المواضع، وتوليد صفوف مطبخ مستقيمة وL وU. هذه صفوف خزائن مستطيلة مع فراغ عند الزوايا، لا خزائن زاوية مصنّعة أو أسطح عمل وأجهزة.
- اتجاه عروق X/Y واضح، وطرائق ظهر غاطس أو خارجي ذات إحداثيات متسقة. الملفات القديمة تظل في نمط legacy حتى يغيّره المستخدم صراحة.
- تخصيصات الحواف تتبع الحجرة والرف الصحيح عند تغيير عدد الرفوف؛ أرقام العرض القديمة تبقى قابلة للقراءة.
- تقدير تكلفة بأسعار المستخدم للخامات والحواف والهدر والعمل والمستلزمات والمصاريف وهامش الربح، ودقة العملة تشمل OMR ثلاث منازل. الأسعار الناقصة تظهر كتقدير غير مكتمل؛ النموذج تقدير مساحة اسمية وليس شراء ألواح محسنًا.
- عشر مراجعات محلية مسماة، بحد تخزين 4 MiB، مستقلة عن الحفظ التلقائي. صدّر JSON للاحتفاظ بنسخ قابلة للنقل.
- مكتبة بيانات مرجعية من ملفات HTML ودليل PolyBoard ومثال مخرجاته: بحث وتنزيل JSON وقوالب غرف محوّلة من cm إلى mm، دون تطبيق أسعار أو ثقوب المصدر تلقائيًا. اقرأ [التحليل الموحّد](analysis/SUMMARY_AR.md).

للتجربة: افتح تبويب **Room plan** لإنشاء ترتيب، ثم **Cost estimate** لإدخال الأسعار، و**Engineering review** لحفظ مراجعة، و**Reference library** لفحص البيانات المرفوعة.

اختبار التحمل اختياري بعد البناء: `ENDURANCE_SECONDS=180 npm run test:endurance`. يجمّد نسخة من `dist` ويختبرها محليًا؛ لتغيير مجلد حفظ النتائج استخدم `ENDURANCE_OUTPUT`، والمنفذ `ENDURANCE_PORT`. لا يتصل هذا الاختبار بمواقع خارجية.
